# Pre-submission AL Compliance Checklist — Algarve

Print, tick, file. Maintained by [Algarve Property Compliance](https://algarvepropertycompliance.com/).

## Section A — Property identity
- [ ] Property type confirmed (moradia / apartamento / estabelecimento de hospedagem)
- [ ] Caderneta predial up to date (matrix registered with Finanças)
- [ ] Licença de Utilização available (or substitute if pre-1951)
- [ ] Habitable area, bedrooms, beds count agreed with Caderneta

## Section B — Operator identity
- [ ] NIF (operator) confirmed
- [ ] IBAN active (PT or SEPA equivalent for VAT refunds)
- [ ] Fiscal representative appointed if non-EU resident
- [ ] Início de Atividade declared with Finanças (CAE 55204 / 55201 / 55202 as applicable)

## Section C — Insurance & safety
- [ ] Civil liability insurance ≥ €75,000 active
- [ ] Insurance proof uploaded to gov.pt
- [ ] ABC fire extinguisher per floor, serviced within 12 months
- [ ] Smoke detector in every bedroom
- [ ] First-aid kit on premises
- [ ] Emergency contact sheet posted

## Section D — Guest reporting
- [ ] SIBA account active (operator registered with AIMA)
- [ ] Arrival reporting workflow tested
- [ ] Departure reporting workflow tested
- [ ] 3-working-day reporting cadence documented for the cleaner / manager

## Section E — Complaints & marketing
- [ ] Physical Livro de Reclamações on premises
- [ ] Electronic Livro de Reclamações registered at livroreclamacoes.pt
- [ ] AL number visible in all online listings (Airbnb / Booking / Vrbo / direct)
- [ ] AL plaque on exterior (apartments only — villas exempt)

## Section F — Tax
- [ ] Category B IRS regime confirmed (simplified or organised)
- [ ] VAT status reviewed against 2025 reform (non-resident → no exemption)
- [ ] Tourist tax: applicable municipality? Filing cadence confirmed?
- [ ] Contribuição extraordinária reviewed (containment-area rule)

## Section G — RNAL maintenance
- [ ] All operator data current
- [ ] Any change in past 10 days filed
- [ ] Renewal cadence noted in calendar

## Section H — Câmara opposition
- [ ] 60-day standard window passed without opposition, or
- [ ] 90-day containment-area window navigated, or
- [ ] N/A (pre-existing AL registration)
